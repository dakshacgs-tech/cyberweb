1. Back up C:\xampp\htdocs\cyberweb-dashboard.
2. Extract this ZIP inside C:\xampp\htdocs\.
3. Confirm that C:\xampp\htdocs\cyberweb-dashboard\index.php exists (no double nested folder).
4. Start Apache and MySQL in XAMPP.
5. Open a new incognito window and visit http://localhost/cyberweb-dashboard/
6. The login page must appear. After signing in the dashboard is index.php. Log out via top-right Sign Out button.
Note: This package uses the existing cyberweb database and does not change the password.
